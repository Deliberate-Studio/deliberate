# How Deliberate works

## One memory, many agents

Deliberate keeps one memory per brand: what the store sells, what customers say, what the ads have done, what the books show, and every finding a person or agent has written down. Each agent reads from it and writes back to it, so what one agent learns reaches the others. The support agent's read on why customers return a product shapes the next ad brief and the next email.

That memory is organized as a research library. A librarian agent (Dorothy) keeps an index of the most current finding on each topic, so agents start from today's answer instead of a year-old one.

## The loop

| Step | What happens |
| --- | --- |
| Read | Agents pull from the brand's connected tools every day. |
| Propose | Work arrives as a card with the evidence attached: an ad, a reply, a budget move, a flag. |
| Decide | A person approves, redirects or ignores it. Approvals route to whoever owns that kind of work. |
| Execute | The agent does the work in the real tool, for example a paused ad in Meta. |
| Learn | The outcome is written back so next week's work starts smarter. |

## Autonomy is earned in stages

1. **Connect.** One-click grants for most tools. Anything not connected stays visible, grayed out.
2. **Read-only.** The agents build their picture and the daily brief starts. Nothing acts.
3. **Proposals.** Work queues for approval, and the brand sets the guardrails.
4. **Autonomy you grant.** Routine loops run unattended, one at a time, only where the brand turns them on.

## Integrations

Shopify, Meta Ads, Google Ads, Klaviyo, Gorgias, Gmail, Google Drive, Slack, QuickBooks, Recharge, Okendo, Triple Whale, ShipBob, ShipHero, Amazon Seller Central and Amazon Ads, YouTube, Typeform and others. When a tool has no API, a browser extension guides a person through it.
